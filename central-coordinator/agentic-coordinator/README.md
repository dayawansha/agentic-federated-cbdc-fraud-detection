# Agentic Coordinator

LangGraph-based orchestration for federated rounds and cross-service workflows.

## Runtime Name
- `agentic-coordinator`

## Responsibilities
- Orchestrate federated learning rounds
- Select participating bank nodes
- Adaptive scheduling based on node performance
- SAGA orchestration for training workflows

## Technology Stack
- Python 3.11+
- FastAPI
- LangGraph/LangChain
- Kafka

## Port
- 8001
