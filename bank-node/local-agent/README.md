# Local Agent

Autonomous bank-node coordinator executing local training workflows, privacy protection pipelines, weight negotiations, and pattern consensus.

## Port
- **`9001`** (REST API)

## Service Responsibilities
The `local-agent` acts as the coordinator's local counterpart inside each bank node, controlling training triggers, executing security pipelines, and participating in peer-to-peer voting protocols.

- **Autonomous Round Workflow**: Runs a LangGraph-driven local training cycle: checks data availability, pulls the latest global model weights from the Model Registry, triggers the GNN for local training, requests Differential Privacy and masking, and posts the final secure update to the Coordinator.
- **Weight Negotiation**: Negotiates training weight allocations based on local dataset sizes, validation F1-scores, and node reliability ratings, ensuring fair contribution mapping.
- **Consensus & Pattern Evaluation**: Evaluates fraud pattern rules broadcasted by the central coordinator. Inspects statistical ranges (indicator thresholds, transaction velocity, error ratios) and submits automated votes (APPROVE/REJECT).
- **Inference Monitoring**: Aggregates local GNN inference predictions, tracking threat alarms and exporting alerts to the Alerting system.

## API Endpoints

### 1. Status & Inference
- `GET /health`: Returns basic health status.
- `GET /agent/status`: Exposes current runtime state, including last round ID and latest validation metrics.
- `GET /agent/inference`: Fetches a list of recent predictions generated by the local GNN.

### 2. Federated Orchestration
- `POST /agent/round/start`: Triggers the local agentic training state machine for the specified round.
- `POST /agent/negotiate/propose-weights`: Receives metrics from peer nodes and outputs suggested weights for the upcoming aggregation.

### 3. Consensus Protocols
- `POST /agent/consensus/evaluate-pattern`: Evaluates a global threat proposal and returns a structured vote with rationale.
- `POST /agent/consensus/propose-pattern`: Initiates a new fraud pattern proposal to be broadcasted to the coordinator.

| `LOCAL_GNN_URL` | Destination for training & inference requests | `http://local-gnn:9002` |
| `PRIVACY_LAYER_URL`| Destination for applying DP and masks | `http://privacy-layer:9003` |
| `COORDINATOR_URL` | Central orchestration endpoint | `http://agentic-coordinator:8001` |
